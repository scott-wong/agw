# AGW Brand Assets

The AGW identity uses a hexagonal security boundary, three converging request
paths, a central routing node, and one forwarded exit. The palette is deep navy,
electric cyan, steel blue, and cloud white.

| File | Usage |
|------|-------|
| `agw-logo.svg` | Primary light-background lockup |
| `agw-logo-dark.svg` | Dark-background lockup |
| `agw-mark.svg` | Transparent light-background mark |
| `agw-mark-dark.svg` | Transparent dark-background mark |
| `agw-favicon.svg` | SVG favicon |
| `favicon.ico` | Multi-resolution browser/Windows fallback |
| `agw-mark-16.png` … `agw-mark-512.png` | Raster mark sizes |
| `agw-social-preview.png` | GitHub social preview, 1280 × 640 |

Do not put SM2, national-cryptography, lock, or shield symbols into the core
identity. Those are runtime capabilities, not the product's visual category.
