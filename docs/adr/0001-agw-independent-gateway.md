# AGW 作为独立开源项目从零建立历史

AGW 独立开源发布，不复用既有内部网关仓库的 git 历史：仓库从一份快照重新
`git init`，提交历史、issue、发布记录都从本仓开始。理由是内部历史里含有组织、
渠道与内部流水线痕迹，逐条清理比重开一条历史更贵且更难证明清理完整；而对外开放后
使用者真正需要追溯的是"上游 APISIX 基线 + 本仓改动"，这两者都由 `baseline.env`
与全新历史覆盖。

## Consequences

- 版本号从 `3.18.0-agw.1` 起算，与内部网关的版本线彼此独立，互不追溯。
- 内部网关的历史发布记录不进入本仓；如需对照，由外部渠道自行引用。
- 品牌一致性由 `scripts/verify-debrand.sh` 门禁保证，而不是靠人工校对。
